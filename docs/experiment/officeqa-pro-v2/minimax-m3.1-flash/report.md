## 运行与补测来源

[Evaluator 原始运行报告](run-reports.zip)含 10 种 Solver 的 20 份报告。Codex 第 `67` 题取自单题补测，其余补测与初始记录按题合并。Qwen Code 的 90 条记录来自一次独立全量运行。

[MiniMax Code 逐题快照](minimax-code-snapshot.json)保留 90 条最终计分记录。`taskId` 对应题库的 `uid`，`score` 为 0 或 1。准确率用得分之和除以记录数。用 `solveDurationMs` 复算求解耗时分位数，排除 `solveTimedOut` 为 `true` 的题。Token 用量分位数取自 `totalTokens`。中位数和 P90 使用同一线性插值方法，耗时与 Token 分别四舍五入至秒和万 Token。
