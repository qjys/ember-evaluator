# 推荐场景性能测评

新增 recommendation Benchmark、SGLang-GR Solver 和离线 Metrics。每个长度是一项任务，预热、计数器窗口和正式请求属于同一 attempt。任务串行，服务由实验者在同机提前启动。

来源锁记录每个 prompt 文件和两级 catalog 的 SHA-256。标准场景固定五档及负载；自定义场景逐档指定文件。比较依据为同一硬件、模型和词表版本、相同的数据和负载、相同的请求与计时口径。历史 910B2 eager 读数的软件版本及测量窗口不同，只能作为参考。

正式响应的有效性、测量覆盖、快路命中、性能门槛分别呈现。离线指标从逐请求记录与窗口计数器重建。算子 profiler 单独执行。
